Vous avez perdu un document

La recherche est gratuite et vous n'avez pas besoin de créer de compte.

  1. Ouvrez « J'ai perdu un document »

    Cliquez sur ce bouton dans le menu ou sur la page d'accueil.

    Pourquoi ? C'est ici que se trouvent toutes les déclarations de personnes qui ont trouvé un document. Chercher ne coûte rien.

  2. Renseignez le nom, le type de document et la ville

    Écrivez le nom et les prénoms complets tels qu'ils figurent sur le document, choisissez son type (passeport, carte d'identité, permis…) et indiquez la ville où vous pensez l'avoir perdu.

    Pourquoi ? Ces trois informations permettent de retrouver la bonne déclaration. Les accents, les majuscules et l'ordre des noms n'ont pas d'importance.

  3. Reconnaissez votre document sur les photos

    Si une déclaration correspond, vous voyez deux photos du document. Vérifiez que c'est bien le vôtre.

    Pourquoi ? Le numéro du document est masqué et un filigrane est ajouté aux photos pour protéger son propriétaire. Vous seul pouvez reconnaître votre document à son aspect, sa photo ou son état.

  4. Demandez à contacter la personne

    Cliquez sur « C'est mon document : contacter ». Une fenêtre s'ouvre : indiquez votre nom et votre numéro de téléphone.

    Pourquoi ? Les coordonnées de la personne qui a trouvé le document restent cachées tant que la commission n'est pas payée. Cela la protège des curieux et des faux propriétaires.

  5. Payez la commission par Mobile Money

    Vous êtes redirigé vers la page de paiement sécurisée de notre partenaire Sebpay. Choisissez votre pays et votre opérateur, saisissez votre numéro, puis confirmez sur votre téléphone avec votre code secret.

    Pourquoi ? Le paiement est un paiement unique pour débloquer ce contact. Avant de payer, vérifiez que votre solde couvre le montant (plus d'éventuels frais de votre opérateur). La page de paiement reste valable 30 minutes : au-delà, recommencez simplement.

  6. Récupérez les coordonnées et gardez votre code d'accès

    Après le paiement, vous voyez les coordonnées de la personne et un code d'accès. Notez ce code ou gardez-le en lieu sûr.

    Pourquoi ? Ce code vous permet de retrouver ces coordonnées plus tard, depuis la page « Mes accès », sans payer une seconde fois.

  7. Fixez un rendez-vous dans un lieu public

    Appelez la personne et donnez-vous rendez-vous dans un lieu public, à la vue de tous. Vérifiez votre document, récupérez-le, puis remettez-lui en main propre une indemnité de déplacement (minimum conseillé : affiché dans la fenêtre de paiement).

    Pourquoi ? Cette indemnité remercie la personne pour son temps et son déplacement. Elle ne se paie qu'après avoir vérifié et récupéré votre document, jamais avant.

Vous avez trouvé un document

Merci de rendre service ! La déclaration est entièrement gratuite.

  1. Ouvrez « J'ai trouvé un document »

    Choisissez le type de document, recopiez le nom et les prénoms complets figurant dessus, et indiquez la ville où vous l'avez trouvé.

    Pourquoi ? Le propriétaire fera sa recherche avec ces mêmes informations. Plus elles sont exactes, plus il a de chances de vous trouver.

  2. Ajoutez deux photos

    Photographiez le recto, puis le verso ou un autre angle. Masquez le numéro du document avec le doigt ou un papier avant de prendre la photo.

    Pourquoi ? Les photos permettent au propriétaire de reconnaître son document. Le numéro est une information sensible : personne d'autre que le propriétaire ne doit pouvoir le lire. Les photos sont réduites automatiquement avant l'envoi.

  3. Dites où se trouve le document

    Choisissez « Je garde le document sur moi » ou « Je l'ai déposé dans un établissement public ». Dans le second cas, décrivez le lieu avec précision (nom, rue, point de repère).

    Pourquoi ? Le propriétaire doit savoir comment récupérer son document. Si vous l'avez déposé, vous pouvez même rester anonyme : le lieu suffit.

  4. Renseignez vos coordonnées

    Indiquez votre nom et votre téléphone (e-mail, ville et quartier sont facultatifs).

    Pourquoi ? Vos coordonnées restent cachées. Elles ne sont communiquées qu'au propriétaire, une fois qu'il a payé la commission.

  5. Attendez la publication, puis le contact

    Notre équipe vérifie votre déclaration avant de la publier. Quand le propriétaire se manifeste, il vous appelle et vous convenez d'un rendez-vous dans un lieu public.

    Pourquoi ? La vérification évite les fausses déclarations. Au rendez-vous, vérifiez l'identité de la personne avant de remettre le document. Elle vous remet une indemnité de déplacement en main propre.

Retrouver vos coordonnées : « Mes accès »

  • Sur le même appareil : vos accès débloqués apparaissent automatiquement dans la rubrique « Sur cet appareil ».
  • Sur un autre appareil ou après avoir vidé le navigateur : collez votre code d'accès dans « Utiliser un code d'accès » et cliquez sur « Consulter ».
  • Vous ne payez qu'une fois : tant que vous avez votre code, vous pouvez revenir consulter les coordonnées sans repayer.
  • Après le rendez-vous : cliquez sur « J'ai récupéré mon document » pour clôturer la demande. Si le document ne correspond pas, ou si la déclaration vous paraît frauduleuse, cliquez sur « Signaler un problème » : notre équipe examine votre signalement.

Pourquoi payer des frais de service ?

Chercher et déclarer un document sont gratuits. Seul le déblocage des coordonnées est payant : une commission de montant affiché avant le paiement, payée une seule fois.

À quoi sert cette commission ?

Faire vivre le service

Hébergement du site, maintenance et amélioration de l'application, pour qu'elle reste disponible quand vous en avez besoin.

Vérifier les déclarations

Chaque déclaration est contrôlée avant publication, pour limiter les fausses annonces et les abus.

Sécuriser le paiement

Le paiement Mobile Money passe par un partenaire de paiement agréé, qui prélève des frais de transaction.

Protéger les coordonnées

Un petit paiement décourage ceux qui voudraient récupérer des numéros de téléphone sans être propriétaires d'un document.

Ce que la commission n'est pas

  • Ce n'est pas le prix de votre document. Un document n'est jamais « vendu » : il est rendu à son propriétaire.
  • Ce n'est pas l'indemnité du déclarant. L'indemnité de déplacement est remise directement à la personne qui a trouvé le document, en main propre, sans passer par nous.

Et l'alerte payante ?

Si votre recherche ne donne aucun résultat, le site vous propose d'activer une alerte (tarif affiché au moment de l'activation), payable par Mobile Money. Dès qu'un document correspondant est déclaré, notre équipe vous prévient par e-mail et par appel, sans que vous ayez à relancer la recherche. Ce tarif couvre ce suivi et ces notifications.

Votre sécurité avant tout

  • Donnez-vous toujours rendez-vous dans un lieu public, à la vue de tous.
  • Ne versez jamais l'indemnité à l'avance, ni par Mobile Money : elle se remet en main propre, après avoir vérifié et récupéré votre document.
  • Si vous avez trouvé un document, vérifiez l'identité du propriétaire avant de le lui remettre.
  • Le seul paiement fait sur ce site est la commission, via la page de paiement Sebpay. Méfiez-vous de toute personne qui vous demande de payer ailleurs.

Questions fréquentes

Je ne trouve pas mon document, que faire ?

Vérifiez l'orthographe du nom, le type de document et essayez les villes proches. Il est aussi possible que personne ne l'ait encore déclaré : revenez plus tard ou activez une alerte pour être prévenu.

Je n'ai reçu aucune notification sur mon téléphone après avoir cliqué sur « Payer »

Sur la page Sebpay, vérifiez que vous avez bien choisi votre pays et votre opérateur, saisi votre numéro et validé. Vérifiez aussi que le solde de votre compte Mobile Money est suffisant : un solde insuffisant est la cause la plus fréquente. Si la page a expiré (30 minutes), recommencez la demande.

J'ai payé mais je ne vois pas les coordonnées

Patientez quelques instants sur la page : la confirmation du paiement peut prendre un peu de temps. Ne payez pas une deuxième fois. Si rien n'apparaît, gardez le message de confirmation de votre opérateur (montant, heure, numéro) et contactez-nous (voir la rubrique « Nous contacter » juste en dessous).

Dois-je payer à chaque fois que je consulte les coordonnées ?

Non. Le paiement est unique pour un déblocage. Gardez votre code d'accès pour les retrouver à tout moment depuis « Mes accès ».

Mes coordonnées sont-elles visibles de tous si je déclare un document ?

Non. Elles restent cachées et ne sont communiquées qu'au propriétaire du document, après son paiement. Si vous déposez le document dans un établissement public, vous pouvez aussi rester anonyme.

Pourquoi dois-je masquer le numéro du document sur les photos ?

Les photos sont visibles par tous ceux qui effectuent une recherche. Le numéro est une donnée sensible, qui pourrait servir à usurper l'identité du propriétaire. Masquez-le avec le doigt ou un papier avant de photographier.
